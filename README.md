# maiarowsky/tap

Homebrew formulae by maiarowsky.

```sh
brew install maiarowsky/tap/dayhand
```

| Formula | What it is |
|---|---|
| `dayhand` | [Dayhand](https://dayhand.dev)'s command line, `dayhand` and `dh`, for people and AI agents ([source](https://github.com/maiarowsky/dayhand)) |

The formula is kept in the Dayhand repository as `packaging/homebrew/dayhand.rb` and copied here with the
checksum of the npm tarball at each release ([docs/release.md](https://github.com/maiarowsky/dayhand/blob/main/docs/release.md)).
